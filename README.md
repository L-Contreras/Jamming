Spotify Playlist Maker
A React-based app that allows users to create and manage playlists using the Spotify API. You can search for songs, add them to your playlist, remove songs, and connect your Spotify account to make the experience more personalized.

Features
Search for songs: Easily find songs using the Spotify API.

Create playlists: Add songs to a playlist of your choice.

Remove songs: Remove songs from your playlist with a click.

Spotify Authentication: Connect your Spotify account using OAuth for personalized playlist management.

Tech Stack
React: Used for building the user interface.

Spotify API: For searching songs and managing playlists.

OAuth: For authenticating users and connecting to their Spotify accounts.

CSS: For styling and ensuring a responsive design.
